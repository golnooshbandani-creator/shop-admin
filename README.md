# ShopAdmin — E-commerce Admin Dashboard

A simple and responsive e-commerce admin dashboard built with Angular. This project is part of my front-end development learning journey, focusing on Angular fundamentals, component-based architecture, and product management.

## Features

- **Dashboard Overview:** Displays store status and key statistics, including total sales and orders.
- **Product Management:** Add, edit, and delete products.
- **Search Products:** Find products by name.
- **Sort Products:** Sort products by price, from low to high or high to low.
- **Persistent Storage:** Save product data in the browser using `localStorage`, so changes remain after refreshing the page.
- **Reusable Architecture:** Separate product-related logic into an Angular service.
- **Reactive UI:** Use Angular Signals and `computed()` to keep the interface updated when product data changes.

## Technologies Used

- Angular
- TypeScript
- HTML
- CSS
- Angular Signals
- Angular Services and Dependency Injection
- Browser `localStorage`
- Git and GitHub

## What I Learned

Through this project, I practiced building standalone Angular components, working with Signals, creating services, using Dependency Injection, managing product data, implementing CRUD operations, and saving data in browser storage.

## Getting Started

Make sure Node.js and npm are installed.

```bash
git clone https://github.com/golnooshbandani-creator/shop-admin.git
cd shop-admin
npm install
ng serve
```

Open `http://localhost:4200/` in your browser.

## Current Status

This project is under active development. More features and improvements will be added as I continue learning Angular and building practical front-end projects.

# ShopAdmin — پنل مدیریت فروشگاه اینترنتی

یک پنل مدیریت فروشگاه اینترنتی ساده و واکنش‌گرا که با Angular ساخته شده است. این پروژه بخشی از مسیر یادگیری من در توسعه فرانت‌اند است و بر مفاهیم پایه Angular، معماری مبتنی بر کامپوننت و مدیریت محصولات تمرکز دارد.

## قابلیت‌ها

- **نمای کلی داشبورد:** نمایش وضعیت فروشگاه و آمارهای اصلی، از جمله مجموع فروش و تعداد سفارش‌ها.
- **مدیریت محصولات:** افزودن، ویرایش و حذف محصولات.
- **جست‌وجوی محصولات:** پیدا کردن محصولات بر اساس نام.
- **مرتب‌سازی محصولات:** مرتب‌سازی بر اساس قیمت، از کم به زیاد یا از زیاد به کم.
- **ذخیره‌سازی اطلاعات:** ذخیره اطلاعات محصولات در مرورگر با استفاده از `localStorage` تا تغییرات پس از رفرش صفحه باقی بمانند.
- **ساختار قابل توسعه:** جداسازی منطق مربوط به محصولات در یک سرویس Angular.
- **رابط کاربری واکنش‌گرا:** به‌روزرسانی خودکار رابط کاربری با استفاده از Angular Signals و تابع `computed()` هنگام تغییر اطلاعات محصولات.
